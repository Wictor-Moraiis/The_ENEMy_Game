# The_ENEMy_Game
The_ENEMy_Game é um jogo inspirado no ENEM, onde uma garota ansiosa para a prova adormece e entra em sonhos baseados no primeiro e segundo dia do exame. Em cada fase, o jogador responde questões para enfrentar desafios e derrotar os inimigos de cada dia, unindo educação, raciocínio e entretenimento.
